# Frontend Mentor - Advice Generator App

This is my solution to the **Advice Generator App** challenge on Frontend Mentor. This project helped me practice working with APIs, asynchronous JavaScript, DOM manipulation, and responsive web design.


## 🚀 Features

- Fetches random advice using the Advice Slip API
- Displays advice ID and advice text
- Generates a new random advice on every button click
- Responsive design for mobile and desktop
- Interactive hover effect on the dice button
- Error handling using `try...catch`

---

## 🛠️ Built With

- HTML5
- CSS3
- CSS Variables
- Flexbox
- JavaScript (ES6+)
- Fetch API
- Async/Await

## 📚 What I Learned

While building this project, I learned:

- How to fetch data from an external API using the Fetch API.
- Using `async` and `await` to handle asynchronous operations.
- Parsing JSON responses from an API.
- Updating the DOM dynamically with JavaScript.
- Handling API errors using `try...catch`.
- Creating responsive layouts using CSS.
- Using CSS custom properties (variables) to keep styles consistent.

---

## 💡 Challenges Faced

Some challenges I encountered were:

- Understanding the structure of the JSON response returned by the API.
- Learning how asynchronous JavaScript works.
- Positioning the floating dice button correctly.
- Understanding browser caching when requesting data repeatedly.
