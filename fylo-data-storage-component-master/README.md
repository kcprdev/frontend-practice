# Frontend Mentor - Fylo Data Storage Component Solution

This is my solution to the **Fylo Data Storage Component** challenge on Frontend Mentor. The project focuses on building a responsive storage dashboard using only HTML and CSS while matching the provided design as closely as possible.

## 📖 Overview

### The Challenge

Users should be able to:

- View the optimal layout depending on their device's screen size.
- Experience a responsive design for both desktop and mobile devices.
